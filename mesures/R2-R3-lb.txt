
==========================================================================
Preuves R2 (idempotence) et R3 (scalabilite) - repartiteur lb1
Date : 28/10/2026 - Poste : BANCE F.X. (i5-4300U, 8 Go, Windows)
==========================================================================

Commandes executees :
  1. vagrant provision lb1                       -> application de la config
  2. curl.exe -i http://localhost:8080           -> 503 attendu (aucun serveur sain)
  3. vagrant provision lb1                       -> rejeu sans changement (R2)
  4. $env:NB_APP=4; vagrant provision lb1        -> passage a 4 serveurs (R3)
  5. vagrant ssh lb1 -c "grep server ..."        -> verification du fichier genere
  6. vagrant provision lb1                       -> retour a 2 serveurs
  
Commentaire :
  - Rejeu 1 : "configuration inchangee : rien a faire" -> le script est
    idempotent, HAProxy n'est pas recharge inutilement (R2).
  - NB_APP=4 : 4 lignes "server" generees depuis noeuds.yml, sans aucune
    modification manuelle de la configuration (R3).
  - Le retour a NB_APP=2 retire app3 et app4 : la configuration suit
    toujours la source unique de verite.
  - curl renvoie 503 "No server is available" : les serveurs applicatifs
    n'existent pas encore, la sonde /sante les declare morts et HAProxy
    refuse de leur envoyer du trafic. La sonde est donc reellement
    appliquee (R4, piege n°6).
